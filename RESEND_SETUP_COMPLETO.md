# Setup Resend.com Automatico per Tutti i Clienti

## PROBLEMA ATTUALE
Resend blocca le email perché non riconosce il mittente come verificato.
Per funzionare automaticamente per TUTTI i clienti serve configurazione dominio.

## SOLUZIONE DEFINITIVA: Configurazione Dominio Resend

### PASSO 1: Registra Dominio
Opzioni economiche:
- `lamiagazella.com` su Namecheap (~€10/anno)
- `gazellanutrizione.com` 
- `miagazzella.it`

### PASSO 2: Configura Dominio in Resend
1. Dashboard Resend → "Domains" 
2. Clicca "Add Domain"
3. Inserisci il tuo dominio (es: `lamiagazella.com`)
4. Copia i record DNS forniti da Resend

### PASSO 3: Aggiungi Record DNS
Nel pannello del tuo provider dominio aggiungi:
- Record TXT per verifica
- Record MX per email  
- Record CNAME per tracking

### PASSO 4: Verifica Automatica
Resend verificherà il dominio automaticamente (5-30 minuti)
